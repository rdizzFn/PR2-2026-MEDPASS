# Planificación del proyecto – MedPass

## 1. Objetivo

Establecer las etapas de trabajo necesarias para desarrollar, probar y organizar el sistema MedPass, definiendo las responsabilidades de cada integrante y las actividades principales.

## 2. Etapas del proyecto

| Etapa | Actividades | Responsable |
|---|---|---|
| 1. Análisis y planificación | Identificación del problema, objetivos y requisitos | Ambos integrantes |
| 2. Diseño del sistema | Diseño de la arquitectura, flujograma y base de datos | Ambos integrantes |
| 3. Desarrollo del Backend | Implementación de consultas, conexiones y operaciones con la base de datos | Rodrigo Castillo |
| 4. Desarrollo del Frontend | Diseño e implementación de formularios e interfaces | Andres Martinez |
| 5. Integración | Conexión de las interfaces con las operaciones del sistema | Ambos integrantes |
| 6. Pruebas | Verificación de módulos, funcionalidades y operaciones | Ambos integrantes |
| 7. Documentación | Organización y actualización de documentos del proyecto | Ambos integrantes |

## 3. Dependencias entre actividades

- El análisis y la definición de requisitos sirven como base para el diseño.
- El diseño de la base de datos y la arquitectura orientan el desarrollo.
- El Backend y el Frontend deben integrarse para comprobar el funcionamiento completo.
- Las pruebas permiten identificar errores y realizar correcciones.
- La documentación debe actualizarse conforme avance el proyecto.

## 4. Responsables

- **Rodrigo Castillo:** desarrollo del Backend y administración de la base de datos.
- **Andres Martinez:** desarrollo del Frontend.
- **Ambos integrantes:** análisis, diseño, integración, pruebas y documentación.

## 5. Cronograma

El cronograma general del proyecto se encuentra en el archivo `gantt.pdf`, ubicado en esta misma carpeta.

Las actividades y sus fechas podrán ajustarse según los avances y las necesidades del equipo.

## 6. Seguimiento

El cumplimiento de las actividades se registrará en `seguimiento.md` y mediante GitHub Issues.
