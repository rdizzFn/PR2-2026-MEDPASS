# Visión y Alcance del Proyecto MedPass

## 1. Visión del proyecto

MedPass es un sistema de gestión de reservas médicas que busca facilitar la organización de clínicas y consultorios mediante la centralización de la información de pacientes, médicos, especialidades, horarios, citas, historiales clínicos y pagos.

El sistema tiene como finalidad mejorar la administración de las citas médicas, reducir errores en las reservas y facilitar el acceso a la información según el rol de cada usuario.

## 2. Problema que busca resolver

En muchos centros médicos, la gestión de citas se realiza mediante llamadas, mensajes o registros manuales. Esta forma de trabajo puede ocasionar citas duplicadas, problemas con los horarios disponibles y dificultades para consultar, cancelar o modificar reservas.

MedPass busca solucionar estas dificultades mediante un sistema que permita organizar la información y gestionar las reservas desde un solo lugar.

## 3. Usuarios del sistema

El sistema está dirigido principalmente a los siguientes usuarios:

- **Administrador:** puede gestionar usuarios y médicos.
- **Recepcionista:** puede gestionar pacientes, citas y pagos.
- **Médico:** puede consultar sus citas, pacientes, horarios e historiales clínicos.

También está orientado a clínicas y consultorios médicos que necesitan mejorar la organización de sus actividades.

## 4. Objetivos del proyecto

- Registrar y organizar la información de pacientes, médicos y especialidades.
- Permitir la reserva de citas tomando en cuenta los horarios disponibles.
- Facilitar la modificación y cancelación de citas.
- Mostrar los horarios disponibles de los médicos.
- Reducir errores relacionados con reservas duplicadas y problemas de horarios.

## 5. Alcance del sistema

MedPass contempla el desarrollo de una aplicación de escritorio que permita realizar las siguientes funciones:

- Inicio de sesión y control de acceso según el rol del usuario.
- Gestión de pacientes.
- Gestión de médicos.
- Gestión de especialidades.
- Gestión de citas médicas.
- Gestión de horarios disponibles.
- Consulta de historiales clínicos.
- Gestión de pagos.

Las funciones disponibles para cada usuario dependerán de los permisos correspondientes a su rol.

## 6. Tecnologías utilizadas

Para el desarrollo del proyecto se contemplan las siguientes tecnologías y herramientas:

- **Lenguaje de programación:** C#
- **Entorno de desarrollo:** Visual Studio
- **Framework:** .NET Framework
- **Base de datos:** SQL Server
- **Gestión de base de datos:** SQL Server Management Studio
- **Control de versiones:** GitHub
- **Diseño de diagramas:** Draw.io

## 7. Resultado esperado

Se espera contar con un sistema que permita gestionar de manera organizada la información médica y las reservas, facilitando el trabajo del personal administrativo y médico, además de mejorar la organización de las citas para los centros médicos.

## 8. Límites del alcance

El informe inicial no establece funcionalidades excluidas del proyecto. Por tanto, cualquier ampliación o función adicional deberá definirse y documentarse durante el desarrollo.
