# Integrantes y roles – MedPass

## 1. Descripción del equipo

MedPass es desarrollado por un equipo de dos integrantes, quienes distribuyen las responsabilidades de acuerdo con las áreas principales del sistema.

## 2. Integrantes y responsabilidades

### Rodrigo Castillo
**Rol:** Backend y Base de Datos.

Responsabilidades:
- Desarrollar la lógica del sistema.
- Implementar las operaciones de acceso a datos.
- Diseñar y administrar la base de datos en SQL Server.
- Implementar la conexión entre el sistema y la base de datos.
- Apoyar en la integración y pruebas del sistema.

### Andres Martinez
**Rol:** Frontend.

Responsabilidades:
- Diseñar las interfaces gráficas del sistema.
- Implementar los formularios de Windows Forms.
- Organizar los elementos visuales y la navegación.
- Apoyar en la integración de las interfaces con el Backend.
- Participar en las pruebas de funcionamiento.

## 3. Trabajo en equipo

Ambos integrantes participan en el análisis, diseño, integración, pruebas y documentación del proyecto.

La comunicación y coordinación entre los integrantes permite mantener organizadas las actividades y dar seguimiento a los avances de MedPass.
