# Acuerdos de trabajo – MedPass

## 1. Objetivo

Establecer acuerdos de organización y colaboración entre los integrantes durante el desarrollo del sistema MedPass.

## 2. Distribución del trabajo

- Rodrigo Castillo se encarga principalmente del Backend y la Base de Datos.
- Andres Martinez se encarga principalmente del Frontend.
- Ambos integrantes participan en las actividades de análisis, diseño, integración, pruebas y documentación.

## 3. Comunicación y coordinación

- Mantener comunicación sobre el avance de las actividades.
- Informar cuando se realicen cambios importantes en el proyecto.
- Consultar con el otro integrante antes de modificar partes que puedan afectar su trabajo.
- Comunicar los problemas encontrados durante el desarrollo.

## 4. Organización del código

- Mantener los archivos organizados según su función.
- Utilizar nombres descriptivos para los archivos, clases y métodos.
- Evitar duplicar código y documentación.
- No incorporar cambios sin comprobar que funcionen correctamente.

## 5. Uso de GitHub

- Registrar los avances mediante commits descriptivos.
- Utilizar GitHub Issues para organizar tareas y reportar errores.
- Revisar los cambios antes de incorporarlos al repositorio.
- Mantener actualizada la documentación del proyecto.

## 6. Pruebas y mantenimiento

- Comprobar el funcionamiento de las modificaciones realizadas.
- Corregir los errores identificados.
- Verificar que los cambios no afecten otras funcionalidades.
- Mantener el proyecto organizado para facilitar su mantenimiento.

## 7. Cumplimiento de los acuerdos

Los integrantes deben aplicar estos acuerdos durante el desarrollo para facilitar la colaboración, evitar conflictos y mantener un avance organizado del proyecto.
