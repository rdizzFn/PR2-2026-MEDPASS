# Guía de contribución – MedPass

## 1. Objetivo

Este documento establece las pautas para colaborar en el desarrollo y mantenimiento del sistema MedPass.

## 2. Organización del equipo

- **Rodrigo Castillo:** Backend y Base de Datos.
- **Andres Martinez:** Frontend.

Cada integrante debe trabajar en las tareas correspondientes a su responsabilidad y coordinar los cambios con el otro integrante.

## 3. Reglas de trabajo

- Mantener el código organizado y legible.
- Utilizar nombres descriptivos para clases, métodos y variables.
- Evitar modificar funcionalidades de otros módulos sin coordinación previa.
- No subir contraseñas, credenciales ni información sensible al repositorio.
- Mantener actualizada la documentación cuando se realicen cambios importantes.

## 4. Control de versiones

- Realizar commits con mensajes claros que describan los cambios.
- Utilizar GitHub Issues para registrar y dar seguimiento a tareas y errores.
- Revisar los cambios antes de incorporarlos a la rama principal.
- Evitar subir archivos temporales o generados por Visual Studio.

## 5. Pruebas

Antes de incorporar cambios al proyecto, se recomienda:

- Comprobar que el proyecto compile correctamente.
- Probar las funcionalidades modificadas.
- Verificar que las operaciones con la base de datos funcionen correctamente.

## 6. Tecnologías del proyecto

- C#
- Windows Forms
- .NET Framework 4.7.2
- Microsoft SQL Server
- ADO.NET
- Visual Studio

## 7. Comunicación

Los integrantes deben mantener comunicación durante el desarrollo, informar sobre los cambios realizados y coordinar las tareas pendientes para evitar conflictos en el código.
