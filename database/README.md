# Base de datos de MedPass

En esta carpeta se encuentra el script SQL para crear la estructura de la base de datos del sistema de reservas médicas.

## Archivo

- `BD_ReservasMedicas.sql`: contiene las instrucciones para crear las tablas y establecer sus relaciones mediante claves primarias y foráneas.

## Requisitos

- Microsoft SQL Server.
- SQL Server Management Studio (SSMS).

## Instalación

1. Abrir SQL Server Management Studio.
2. Conectarse a una instancia de SQL Server.
3. Abrir el archivo `BD_ReservasMedicas.sql`.
4. Ejecutar el script para crear la base de datos y sus objetos.

## Consideraciones

La configuración de SQL Server puede variar según el equipo. Verificar que la instancia utilizada sea compatible con la configuración de conexión de la aplicación.
